# Debug Helper Skill

## Purpose
Assist with debugging by analyzing error messages, stack traces, and code context to suggest likely causes and fixes.

## When to Use
Use when the user shares an error message, stack trace, or asks why their code is not working.

## Instructions
1. Parse the error message or stack trace
2. Identify the error type and likely root cause
3. Suggest specific fixes with code examples
4. Recommend preventive measures
