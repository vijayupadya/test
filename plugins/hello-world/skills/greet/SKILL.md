# Greet Skill

## Purpose
Generate personalized greetings based on context such as time of day, occasion, or cultural background.

## When to Use
Use this skill when the user asks for a greeting, welcome message, or salutation.

## Instructions
1. Consider the context (time of day, occasion, audience)
2. Generate an appropriate greeting
3. Optionally include a brief well-wish or motivational quote
