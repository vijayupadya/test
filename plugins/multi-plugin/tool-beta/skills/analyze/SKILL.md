# Analyze Skill

## Purpose
Analyze code for complexity metrics and suggest simplifications.

## When to Use
Use when the user asks about code complexity, wants to simplify code, or asks for a code quality assessment.

## Instructions
1. Calculate cyclomatic complexity of functions
2. Identify deeply nested code blocks
3. Find overly long functions or methods
4. Suggest refactoring opportunities with concrete examples
