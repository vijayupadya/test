# Sample Notebooks Repository

**Note: This is a test repository.**

## Introduction

This is a sample repository for demonstrating various notebook examples and workflows.

## Testing

This repository includes a simple calculator module with comprehensive unit tests.

### Running Tests

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Run tests:
   ```
   pytest test_calculator.py -v
   ```

### Test Coverage

The test suite includes 25 tests covering:
- Addition operations (positive, negative, zero, floats)
- Subtraction operations (positive, negative, zero)
- Multiplication operations (positive, negative, zero, identity)
- Division operations (positive, negative, zero, error handling)
- Power operations (positive, zero, negative, fractional exponents)
